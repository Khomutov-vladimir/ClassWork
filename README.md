## איך פותחים את הפרויקט

המאגר הזה נוצר בשבילכם כשלחצתם על קישור המטלה ב-Classroom 50. עובדים **רק** במאגר האישי שלכם.

1. פתחו את Android Studio.
2. בחרו **File > New > Project from Version Control**.
3. הדביקו את כתובת ה-URL של **המאגר האישי שלכם** (מהדף של המאגר ב-GitHub), בחרו תיקייה במחשב ולחצו **Clone**.
4. חכו שהפרויקט ייטען (Gradle Sync).
5. בחרו אמולטור (API 34+) ברשימת המכשירים בסרגל העליון, ולחצו על כפתור ה-Run (המשולש הירוק) שליד בחירת המכשיר.

האפליקציה מופיעה באמולטור בשם **Logcat Escape**.

## איך פותחים את Logcat ומסננים

1. בתחתית חלון Android Studio לחצו על הלשונית **Logcat**.
2. בשדה המסנן שבראש החלונית כתבו `tag:ESCAPE` ולחצו Enter. עכשיו מוצגות רק הודעות הלוג עם התגית הזו.
3. כדי לראות את כל הודעות הלוג של האפליקציה שלכם, השתמשו במסנן `package:mine`.
4. כדי לנקות את Logcat לפני ניסוי, לחצו על סמל הפח.

## חלק א': בורחים מהחדר (30 נק')

* הריצו את האפליקציה וסננו את Logcat לפי `tag:ESCAPE`.
* האפליקציה מסתירה 4 רמזים. כל רמז מופיע ב-Logcat רק באירוע אחר במחזור החיים – נסו לעשות לאפליקציה דברים שמשתמש רגיל עושה לטלפון.
* **טיפ:** רמז אחד מסתתר תחת תגית אחרת – נסו סינון רחב יותר.
* כשיש לכם את 4 המילים, הקלידו אותן לפי הסדר בשדה `Password` ולחצו **Escape!**
* סיסמה נכונה תציג `ESCAPED!`. סיסמה שגויה תציג `Wrong password - check Logcat`.
* המשחק נפתר דרך Logcat בלבד – אל תפתחו את `Vault.java`.
* רשמו את הרמזים שמצאתם בחלק א' של `OBSERVATIONS.md`.

## חלק ב': הודעות הלוג שלכם (40 נק')

ב-`MainActivity.java` כבר מוגדר הקבוע `MY_TAG = "MY_LIFECYCLE"`. הוסיפו שורת `Log.d` לכל אחת מ-6 פונקציות מחזור החיים. ההודעה היא **בדיוק** שם הפונקציה, למשל:

```java
Log.d(MY_TAG, "onCreate");
```

* **3 פונקציות קיימות** (`onCreate`, `onPause`, `onStop`): הוסיפו שורת `Log.d` אחת בתוך כל אחת מהן, במקום שמסומן בהערה `TODO (Part B)`.
* **3 פונקציות חסרות** (`onStart`, `onResume`, `onDestroy`): כתבו את הפונקציה כולה – עם `@Override`, הקריאה ל-`super` ושורת ה-`Log.d`. לדוגמה:

```java
@Override
protected void onStart() {
    super.onStart();
    Log.d(MY_TAG, "onStart");
}
```

בסך הכול: 6 שורות `Log.d`, ו-3 מהן בתוך 3 פונקציות חדשות. בדקו את עצמכם: הריצו את האפליקציה, סננו לפי `tag:MY_LIFECYCLE` – האם ההודעות שלכם מופיעות?

## חלק ג': תצפיות (30 נק')

סננו את Logcat לפי `tag:MY_LIFECYCLE`, נקו אותו לפני כל ניסוי, ובצעו את 5 הניסויים:

1. הפעלה ראשונה של האפליקציה (לחצתם Run).
2. לחיצה על כפתור Home.
3. חזרה לאפליקציה.
4. סיבוב מסך – באמולטור `Ctrl + Left` או `Ctrl + Right` (ודאו שסיבוב אוטומטי פועל).
5. לחיצה על כפתור Back.

ב-`OBSERVATIONS.md` רשמו לכל ניסוי את הסדר המדויק של הודעות `MY_LIFECYCLE`, כמו שהן מופיעות ב-Logcat.

## בונוס (+10 נק')
